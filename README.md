# Project Details
## Brief Overview 
The project requirements for my capstone were very simple, answer a question using a choice of various methods, my chosen method being Multiple Linear Regression.
## Data
The data was obtained on [Kaggle](https://www.kaggle.com/datasets/williamsewell/retail-sales-10k) from my course instructor at the time.
Although the data was clean (very little dirtiness), many tasks to prepare the data for it to be ready for MLR.
## Process
Standardization of variables was a necessary task in this dataset, alongside visual inspection of variables using univariate and bivariate plots.
Regression was performed on the initial model which lead to feature elimination using forward selection.
Once the number of variables was properly reduced, a final model on the training data was created.
The model was then used to predict order values on the test set, which would then be compared to the actual values.
Results of the model were then presented alongside tests to prove that the assumptions of MLR were true.
